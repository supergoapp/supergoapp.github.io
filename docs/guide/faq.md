# 常见问题

## 一定要装 Everything 吗？

搜文件、文件夹需要 [Everything](https://www.voidtools.com/downloads/)（免费，只认文件名，速度极快）。装了没运行时，超级直达会自动在后台启动它；没装时，启动器和文件搜索窗口里有“没有安装 Everything”的提示，点一下打开下载页。不装也能用应用搜索、命令、网页搜索和对话框快速切换。目前支持 Everything 1.4。

## 双击 Ctrl 没反应？

- 是不是在全屏游戏或全屏视频里？默认在全屏程序中不响应，可在 选项 → 热键 里关掉“在全屏应用中禁用”。
- 两次按 Ctrl 要快（每次按住不超过 0.4 秒，两次间隔不超过 0.4 秒），中间不能按别的键。
- 也可以在 选项 → 热键 里把“显示超级直达”改成普通组合键。

## 某个快捷键不管用？

- 输入法自己注册的快捷键（比如有的输入法占用 Ctrl+Shift+C）会先被输入法拦掉，换一个组合键即可。
- 作用范围是“资源管理器”“任意程序”的热键，被别的程序占用时注册不上。

## 对话框工具栏没出现 / 点了没反应？

对话框所属的程序如果是以管理员身份运行的，超级直达也要以管理员身份运行。另外检查 选项 → 第三方集成 里是否关掉了。

## 拼音能搜文件吗？

应用名支持拼音；文件和文件夹名暂不支持（计划中）。

## 数据存在哪？会联网吗？

设置、固定的项、使用记录都在 `%APPDATA%\SuperGo`，只存在本机。超级直达本身不收集任何信息；网页搜索、打开网址时才会用浏览器访问对应网站。
