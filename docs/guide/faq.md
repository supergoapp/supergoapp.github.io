# 常见问题

## 一定要装 Everything 吗？

搜文件、文件夹需要 [Everything](https://www.voidtools.com/downloads/)（免费，只认文件名，速度极快）。

- 装了没运行：超级直达会自动在后台启动它，连上后自动重新搜索。
- 没装：启动器和文件搜索窗口里有“没有安装 Everything”的提示，点一下打开下载页。
- 不装也能用应用搜索、命令、网页搜索、对话框快速切换。

目前支持 Everything 1.4。Everything 1.5（测试版）暂不支持，在计划中。

## 双击 Ctrl 没反应？

- 两次按 Ctrl 要快：每次按住不超过 0.4 秒，两次间隔不超过 0.4 秒，中间不能按别的键。
- 是不是在全屏游戏或全屏视频里？默认在全屏程序中不响应，可在 选项 → 热键 里取消“在全屏游戏和应用中禁用”。
- 托盘里有没有超级直达的图标？没有的话它没在运行，重新打开它。
- 也可以在 选项 → 热键 → 显示超级直达 里换成普通组合键。

## 某个快捷键不管用？

- 输入法自己注册的快捷键（比如有的输入法占用 Ctrl+Shift+C）会先被输入法拦掉，换一个组合键即可。
- “资源管理器”“任意程序”范围的热键，被别的程序占用时注册不上，换一个组合键。
- 改完要点“应用”或“确定”。

见[热键和作用范围](/guide/hotkeys)。

## 对话框工具栏没出现 / 点了没反应？

- 对话框所属的程序如果是以管理员身份运行的，超级直达也要以管理员身份运行。
- 检查 选项 → 第三方集成 里是否关掉了“文件对话框”。
- 用自己做的对话框的程序（比如 WPS 的内置对话框）暂不支持。

## 拼音能搜文件吗？

应用名支持拼音（全拼、首字母，多音字按词组读）；文件和文件夹名暂不支持（计划中）。

## 搜索结果太乱 / 想要的文件找不到？

- 太乱：确认文件搜索窗口左边的“不常用文件”是关着的，把不想看到的文件夹加到 选项 → 文件搜索 → 优先级 的“忽略”里。
- 找不到：打开“不常用文件”再看；或者那个磁盘没被 Everything 索引，在 Everything 的“选项 → 索引”里加上。

## 首页“最近使用”里没有我常用的应用？

首页只统计在**启动器里**打开过的应用和文件夹（以及对话框里用过的文件夹），从开始菜单、桌面图标直接打开的不算。用启动器打开几次就有了；也可以直接固定到首页。

## 界面显示不正常（黑块、花屏）？

选项 → 常规设置 → 勾选“使用软件渲染”。

## 能用别的文件管理器打开文件夹吗？

能。选项 → 常规设置 → 打开文件夹用，填文件管理器的路径和参数。对话框工具栏、打字即搜目前只支持系统的资源管理器和标准对话框。

## 有深色主题、英文界面吗？

还没有，都在计划中。

## 数据存在哪？会联网吗？

设置、固定的项、使用记录、插件都在 `%APPDATA%\SuperGo`，只存在本机。超级直达本身不收集任何信息；只有网页搜索、打开网址时才会用浏览器访问对应网站。

## 怎么卸载？

安装版：在 Windows 的“设置 → 应用”里卸载。便携版：右键托盘图标 → 退出，删掉程序文件夹。想把设置也删掉，再删 `%APPDATA%\SuperGo`。

## 在哪反馈问题？

在 [supergo-release 的 Issues](https://github.com/supergoapp/supergo-release/issues) 里提，写上 Windows 版本、超级直达版本（选项 → 关于）和操作步骤。
