# 文件搜索窗口

完整的文件搜索界面：左边筛选，中间结果，右边预览。

**打开方式**：启动器里再连按两下 Ctrl（带着输入）、点启动器输入框右边的第一个按钮、首页的“文件搜索”格子、托盘菜单“打开新的文件搜索窗口”，或在 选项 → 热键 里给它设一个热键。

## 界面

- **左边**：按类型（全部、文件夹、文件、文档、图片、视频、音频）、最近修改（1 天、7 天、30 天、365 天）筛选；“不常用文件”开关决定是否显示系统文件夹、开发依赖等很少会找的东西。
- **中间**：名称（匹配的部分标蓝）、路径、修改时间；点列头排序，拖动列宽会记住。
- **右边**：预览（Alt+P 开关）。
- **底部**：项目总数；左下角齿轮打开选项。
- **搜索框右端的“?”**：搜索语法速查，点一行把例子填进搜索框。没输入时中间也有几个可以点的例子。

## 预览

用的是 Windows 自带的预览程序（和资源管理器的预览窗格同一套）：文本、代码、Markdown、图片、PDF、Office 文档等，装了对应预览程序的都能直接看。没有预览程序的文本和代码也能显示内容，其余显示缩略图和文件信息。

## 按键

| 按键 | 作用 |
|---|---|
| ↑ ↓ | 选择 |
| Enter / 双击 | 打开 |
| Ctrl+Enter | 打开所在文件夹并选中 |
| Ctrl+O | 动作菜单 |
| Ctrl+C 等动作热键 | 对选中项执行（搜索框里选中了文字时，Ctrl+C 只复制文字） |
| Alt+P | 显示 / 隐藏预览 |
| 右键 | 系统右键菜单 |
| Esc | 关闭（下次打开保留筛选条件） |
