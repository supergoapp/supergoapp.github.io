# 文件搜索窗口

启动器适合“打几个字马上打开”，文件搜索窗口适合“慢慢找”：结果更多，可以按类型、修改时间筛选，按列排序，边看预览边挑。

## 怎么打开

- 启动器里**再连按两下 Ctrl**：带着输入框里的文字切过来；
- 点启动器输入框右边第一个按钮（方框加箭头）；
- 首页的“文件搜索”格子；
- 托盘菜单 → 打开新的文件搜索窗口；
- 命令 `here 词`：只在当前文件夹里搜；
- 在 选项 → 热键 → 文件搜索窗口 里设一个热键。

## 界面

- **顶部**：搜索框。右端的 **?** 打开搜索语法速查，点一行就把例子填进搜索框。
- **左边**：筛选。
  - 类型：全部、文件夹、文件、文档、图片、视频、音频；
  - 最近修改：全部、最近 1 天、7 天、30 天、365 天；
  - **不常用文件**开关：是否显示系统文件夹、程序文件夹、`AppData`、`node_modules`、以 `.` 或 `~` 开头的文件这类平时很少找的东西（默认不显示）。
- **中间**：结果表，有名称（匹配的部分高亮）、路径、修改时间。点列头排序，拖动列宽会记住。
- **右边**：[预览](/guide/preview)，Alt+P 或底部的开关显示 / 隐藏。
- **底部**：项目总数、预览开关；**左下角齿轮**打开选项。

还没输入时，列表中间有一排可以点的例子：`*.mp4`、`报告 !草稿`、`ext:jpg;png`、`dm:thisweek`、`size:>100mb`……点一下就填进搜索框。

## 按键

| 按键 | 作用 |
|---|---|
| ↑ ↓ | 选择 |
| Enter、双击 | 打开 |
| Ctrl+Enter | 打开所在文件夹并选中 |
| Ctrl+O | [动作菜单](/guide/actions) |
| Ctrl+C 等动作热键 | 对选中项执行（搜索框里选中了文字时，Ctrl+C 只复制文字） |
| Alt+P | 显示 / 隐藏预览 |
| 右键 | 系统右键菜单 |
| Esc | 关闭（下次打开保留筛选条件） |

## 搜索语法

输入的内容原样交给 Everything，所以可以组合各种条件：

- `报告 2026`：名字里同时有“报告”和“2026”
- `*.mp4|*.mkv`：mp4 或 mkv
- `报告 !草稿`：有“报告”但没有“草稿”
- `size:>100mb dm:thisweek`：本周改过的大于 100 MB 的文件

完整写法见[搜索语法](/guide/syntax)。

## 搜索结果的优先级

选项 → 文件搜索 → 优先级：给文件夹或名字规则设级别，决定它们在结果里的位置。

| 级别 | 效果 |
|---|---|
| 高 | 排在前面 |
| 正常 | 默认 |
| 不常用文件 | 只有打开左边的“不常用文件”开关时才显示 |
| 忽略 | 永远不出现在结果里 |

可以“添加文件夹”，也可以“添加名字规则”（正则，比如 `^node_modules$`）。在 选项 → 文件搜索 → 索引 里点“从搜索结果中移除文件夹…”，选中的文件夹会加到“忽略”里。

## 索引由 Everything 负责

要搜网络驱动器、排除某些磁盘，在 Everything 自己的“选项 → 索引”里设置。选项 → 文件搜索 → 索引 页能看到 Everything 的状态，有“重建索引”“打开 Everything”两个按钮。

Everything 没运行或没装时，列表中间会显示状态和下一步，点一下列表区域就执行（启动 Everything，或打开下载页）。

## 常见问题

**结果里有很多系统文件、缓存，太乱？**
确认左边“不常用文件”是关着的；再把不想看到的文件夹加到 选项 → 文件搜索 → 优先级 的“忽略”里。

**明明有的文件搜不到？**
可能被归为“不常用文件”了，打开左边的开关再看看；或者它所在的磁盘没被 Everything 索引，在 Everything 的选项里加上。

**能同时开几个文件搜索窗口吗？**
目前只有一个。
