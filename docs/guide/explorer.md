# 资源管理器里打字即搜

在资源管理器的文件列表里（或桌面上），不用点搜索框，直接打字就开始搜：在当前文件夹（桌面上是桌面文件夹）及子文件夹里找名字匹配的文件和文件夹。

## 怎么用

1. 打开资源管理器的某个文件夹，点一下文件列表的空白处（或点一下桌面空白处）。
2. 直接输入几个字，弹出搜索面板，列出匹配的项。
3. Enter 打开（文件夹就在当前窗口跳过去），Ctrl+Enter 打开所在文件夹，Esc 关闭。

## 停用

选项 → 第三方集成：分别关掉“资源管理器”“桌面”。

## 弹出菜单

另一个在资源管理器里好用的功能：在 选项 → 热键 → 显示弹出菜单 里设一个热键（默认没设），在资源管理器或对话框里按它，弹出收藏夹和最近的文件夹，选一个就跳过去，“此电脑”这类系统文件夹也可以。收藏夹在 选项 → 菜单 里改。
