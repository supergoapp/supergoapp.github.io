# 资源管理器里打字即搜

在资源管理器的文件列表里（或桌面上），不用点搜索框，直接打字就开始搜：在当前文件夹及子文件夹里找名字匹配的文件和文件夹，比 Windows 自带的搜索快得多。

## 怎么用

1. 打开资源管理器的某个文件夹，点一下文件列表的空白处。
2. 直接输入几个字，弹出搜索面板，列出匹配的项。
3. 用按键操作：

| 按键 | 作用 |
|---|---|
| ↑ ↓ | 选择 |
| Enter | 打开；文件夹就在当前窗口跳过去 |
| Ctrl+Enter | 打开所在文件夹 |
| Esc | 关闭面板 |

**桌面上也一样**：点一下桌面空白处再打字，就在桌面文件夹里搜。

搜索框里同样能用[搜索语法](/guide/syntax)，比如 `*.pdf`、`dm:thisweek`。

## 例子

在 `D:\项目\官网` 里点一下空白处，输入 `conf` → 面板里列出 `docs\.vitepress\config.mts` 等，回车用默认程序打开。

## 设置项

| 位置 | 设置 |
|---|---|
| 选项 → 第三方集成 | 分别开关“资源管理器”“桌面”的打字即搜 |

## 常见问题

**打字没有弹出面板？**
- 先点一下文件列表的**空白处**，让文件列表有焦点。焦点在地址栏、搜索框或者正在重命名时不会触发。
- 检查 选项 → 第三方集成 里是否关掉了。
- 要用 Everything 搜，Everything 没运行时搜不出来。

**会不会影响资源管理器自己的“按首字母跳转”？**
打字即搜打开后，在文件列表里打字会弹出搜索面板，而不是跳到那个字母开头的文件。不习惯可以在 选项 → 第三方集成 里关掉“资源管理器”。
