# 命令

命令是固定的操作：在启动器里输入关键字（后面可以跟参数），回车执行。很多命令作用于“当前文件夹”，在资源管理器里用起来特别顺手。

## 什么是“当前文件夹”

呼出启动器之前，你正在看的资源管理器、“打开 / 另存为”对话框或桌面的文件夹。从别的程序呼出时，用你的用户文件夹（`C:\Users\你的名字`）。

## 默认的命令

| 关键字 | 作用 |
|---|---|
| `opt` | 打开选项 |
| `rebuild` | 让 Everything 重建索引 |
| `..` | 资源管理器 / 对话框回到上一级文件夹 |
| `mkdir 名字` | 在当前文件夹新建文件夹，并跳进去 |
| `touch 名字` | 在当前文件夹新建文件 |
| `cmd` / `cmda` | 在当前文件夹打开命令提示符 / 以管理员身份打开 |
| `psh` / `psha` | 在当前文件夹打开 PowerShell / 以管理员身份打开。psh 默认热键 Ctrl+Shift+R |
| `codehere` | 用 VS Code 打开当前文件夹 |
| `here 词` | 打开文件搜索窗口，只在当前文件夹里搜 |
| `shutdown` / `reboot` | 4 秒后关机 / 重启 |
| `uninstall` | 打开“卸载程序” |
| `connections` | 打开“网络连接” |
| `hosts` | 以管理员身份用记事本编辑 hosts 文件 |

例子：在资源管理器里打开 `D:\资料`，双击 Ctrl，输入 `mkdir 合同` 回车 → `D:\资料\合同` 建好了，资源管理器已经跳进去；再呼出输入 `..` 回车 → 回到 `D:\资料`。

## 显示在首页

勾了“显示在首页”的命令会出现在两个地方：

- 启动器首页的“操作”一行（对所选文件夹或当前文件夹执行）；
- 文件夹的动作菜单里（对这个文件夹执行；对文件则在它所在的文件夹执行）。

默认勾选的是：创建文件夹、打开命令行窗口、PowerShell、用 VS Code 打开、在此文件夹中搜索。

## 自己加命令

选项 → 命令：点 + 新建一条，填写：

| 项 | 说明 |
|---|---|
| 关键字 | 在启动器里输入的简写 |
| 标题 | 结果里显示的名字 |
| 路径 | 要运行的程序、要打开的文件或网址 |
| 参数 | `{query}` 换成关键字后面输入的文字，`{current_folder}` 换成当前文件夹 |
| 工作目录 | 程序启动时所在的文件夹，可以写 `{current_folder}` |
| 热键 | 不打开启动器，直接按键执行，见[热键和作用范围](/guide/hotkeys) |
| 静默执行 | 不显示窗口（适合脚本） |
| 以管理员身份运行 | 运行时请求管理员权限 |
| 显示在启动器首页的“操作”和文件夹的动作菜单里 | 见上一节 |

不用的命令取消勾选即可停用。插件也能加命令，见[插件](/guide/plugins)。

### 例子：用 Windows Terminal 打开当前文件夹

- 关键字：`wt`
- 标题：在终端中打开
- 路径：`wt.exe`
- 参数：`-d "{current_folder}"`
- 勾选“显示在启动器首页……”

确定后，在资源管理器里双击 Ctrl 输入 `wt` 回车，或者直接点首页“操作”里的“在终端中打开”。

## 常见问题

**`cmd` 打开的不是我想要的文件夹？**
命令用的是呼出启动器**之前**的窗口。先切到那个资源管理器窗口再双击 Ctrl。

**`shutdown` 会不会误触？**
要输入完整关键字并回车才执行，执行后 4 秒关机。
