# 命令和动作

## 命令

在启动器里输入命令的关键字（后面可以跟参数），回车执行。“当前文件夹”是呼出启动器之前那个资源管理器、对话框或桌面的文件夹。

| 关键字 | 作用 |
|---|---|
| `opt` | 打开选项 |
| `rebuild` | 让 Everything 重建索引 |
| `..` | 资源管理器 / 对话框回到上一级 |
| `mkdir 名字` | 在当前文件夹新建文件夹并跳进去 |
| `touch 名字` | 在当前文件夹新建文件 |
| `cmd` / `cmda` | 在当前文件夹打开命令提示符（管理员） |
| `psh` / `psha` | 在当前文件夹打开 PowerShell（管理员），psh 的热键是 Ctrl+Shift+R |
| `codehere` | 用 VS Code 打开当前文件夹 |
| `here 词` | 在文件搜索窗口里只搜当前文件夹 |
| `shutdown` / `reboot` | 关机 / 重启 |
| `uninstall` / `connections` / `hosts` | 卸载程序 / 网络连接 / 编辑 hosts |

在 选项 → 命令 里可以加自己的命令：路径、参数（`{query}` 换成关键字后面的文字，`{current_folder}` 换成当前文件夹）、工作目录、静默执行、以管理员身份运行、热键。

## 动作

对选中的结果（文件、文件夹、应用）做打开以外的事。选中后按 Tab、Ctrl+O，或光标在末尾时按 →，打开动作菜单；菜单里打字可以筛选。

默认的动作：打开所在文件夹（Ctrl+Enter）、复制（Ctrl+C）、剪切、复制路径至剪贴板（Ctrl+Shift+C）、用 VS Code 编辑（Alt+Shift+C），还有删除（进回收站）、复制文件名、固定到启动器首页、“显示在首页”的那些命令（在这个文件夹里打开命令行等）、系统右键菜单。

在 选项 → 动作 里可以加自己的动作：路径、参数（`{action_path}` 换成选中项的路径）、热键、关键字，还能限定**适用条件**：

- 适用于：全部 / 文件 / 文件夹 / 应用；
- 扩展名：如 `md;txt`，只对这些文件出现；
- 路径正则：路径匹配才出现。

## 作用范围

每个动作、命令的热键可以选作用范围：

- **超级直达**（默认）：只在启动器和文件搜索窗口里有效。
- **资源管理器**：在资源管理器或桌面里有效。动作对选中的文件执行，命令在当前文件夹执行。
- **任意程序**：任何时候都有效。

例如把 psh 的作用范围改成“资源管理器”，在资源管理器里按 Ctrl+Shift+R，就在当前文件夹打开 PowerShell。热键被别的程序占用时会注册不上。
