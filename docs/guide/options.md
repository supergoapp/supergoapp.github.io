# 选项一览

超级直达的所有设置都在选项窗口里。

## 怎么打开

- 右键托盘图标 → 选项；
- 启动器输入框右边的齿轮，或首页的“选项”格子；
- 启动器里输入 `opt` 回车；
- 文件搜索窗口左下角的齿轮。

改了设置以后点“**应用**”或“**确定**”才生效，点“取消”放弃这次的修改。

## 各页内容

### 常规设置

| 设置 | 说明 |
|---|---|
| 在 Windows 启动时启动超级直达 | 开机自动启动 |
| 使用软件渲染 | 只在界面显示不正常（比如黑块、花屏）时打开 |
| 启动器位置 → 重置 | 把拖动过的启动器放回屏幕上部居中 |
| 打开文件夹用 | 留空时用资源管理器；也可以填别的文件管理器的路径和参数 |
| 语言 | 目前只有简体中文 |

### 外观

目前只有浅色主题，深色主题在计划中。

### 热键

呼出启动器、再次按下时、全屏时禁用、文件搜索窗口、快速切换、弹出菜单、下一项 / 上一项 / 预览 / 动作。见[热键和作用范围](/guide/hotkeys)。

### 启动器首页

首页开关、固定的项、最近使用的排序和数量、最近记录列表（隐藏 / 取消隐藏 / 清除）。见[启动器首页](/guide/home#设置项)。

### 文件搜索

- **过滤器**：`doc:`、`pic:` 这类简写，每条有名称、关键字、语法，可以改、可以加。见[启动器 · 过滤器](/guide/launcher#过滤器)。
- **索引**：Everything 的状态、重建索引、打开 Everything、从搜索结果中移除文件夹。
- **优先级**：给文件夹或名字规则设“高 / 正常 / 不常用文件 / 忽略”。见[文件搜索窗口 · 优先级](/guide/file-search#搜索结果的优先级)。

### 动作

动作列表（内置的和自定义的），每条的热键、作用范围、关键字、适用于、扩展名、路径正则、标题、路径、参数。见[动作](/guide/actions)。

### 命令

命令列表（勾选启用），每条的热键、作用范围、关键字、标题、路径、参数、工作目录、静默执行、以管理员身份运行、显示在首页。见[命令](/guide/commands)。

### 网络搜索

网页搜索的关键字、标题、网址，勾选启用。见[网页搜索、网址和路径](/guide/web)。

### 菜单

收藏的文件夹，用在[弹出菜单](/guide/popup-menu)和[对话框工具栏](/guide/dialog)的 ☆ 里。

### 第三方集成

分别开关超级直达在这几个地方的功能：

| 开关 | 管的是 |
|---|---|
| 资源管理器 | [资源管理器里打字即搜](/guide/explorer) |
| 文件对话框 | “打开 / 另存为”对话框下方的[工具栏](/guide/dialog) |
| 文件夹对话框 | “选择文件夹”对话框下方的工具栏 |
| 桌面 | 桌面上打字即搜 |

### 插件

已加载的插件，“打开插件文件夹”“重新加载”“新建示例插件”三个按钮。见[插件](/guide/plugins)。

### 关于

版本号和致谢。

## 设置存在哪里

`%APPDATA%\SuperGo`：设置、固定的项、使用记录、插件都在这里，只存在本机。换电脑时把这个文件夹复制过去即可。
