# 插件

插件可以不改程序，就给动作菜单和命令加东西。

## 放在哪

`%APPDATA%\SuperGo\plugins\插件名\`，里面放 `actions.tsv`（动作）和 / 或 `commands.tsv`（命令）。选项 → 插件 里有“打开插件文件夹”“重新加载”“新建示例插件”三个按钮。

## 格式

制表符分隔的 UTF-8 文本，第一行以 `#` 开头，是列名。路径和参数里的 `{plugin_dir}` 会换成插件所在的文件夹。

**actions.tsv** 的列：内置（留空）、标题、路径、参数（`{action_path}` 是选中项的路径）、热键、关键字、作用范围（`app` / `explorer` / `any`）、适用于（空 / `file` / `folder` / `app`）、扩展名、路径正则。

**commands.tsv** 的列：内置（留空）、关键字、标题、路径、参数（`{query}`、`{current_folder}`）、工作目录、热键、静默（0/1）、管理员（0/1）、启用（0/1）、作用范围、显示在首页（0/1）。

## 示例

选项 → 插件 → 新建示例插件，会生成：

- 动作“用记事本打开”：只对 txt、md、log、ini、json 文件出现，关键字 `np`；
- 命令“在资源管理器中打开”：关键字 `exp`，显示在首页的“操作”里。

插件的动作和命令按同样的适用条件显示，不会写进你自己的设置，选项的动作 / 命令页里也不显示。
