# 插件

插件可以不改程序，就给动作菜单和命令加东西。一个插件就是一个文件夹，里面放一两个文本文件，不用会编程，复制给别人就能分享。

## 先试试示例插件

1. 选项 → 插件 → **新建示例插件**，列表里出现“示例插件”（动作 1、命令 1）。
2. 点“确定”。
3. 试一试：
   - 搜一个 .md 或 .txt 文件，按 Tab → 菜单里有“用记事本打开”；输入 `说明 np` 回车，直接用记事本打开（`np` 是它的关键字）。搜 .jpg 则没有这个动作。
   - 在资源管理器里呼出启动器 → 首页“操作”里多了“在资源管理器中打开”（关键字 `exp`）。

## 放在哪

`%APPDATA%\SuperGo\plugins\插件名\`，里面放 `actions.tsv`（动作）和 / 或 `commands.tsv`（命令）。

选项 → 插件 里的三个按钮：

- **打开插件文件夹**：在资源管理器里打开 `plugins`；
- **重新加载**：改了插件文件以后点它，不用重启；
- **新建示例插件**：生成上面那个示例。

删除插件：删掉它的文件夹，点“重新加载”。

## 文件格式

用 UTF-8 保存的文本文件，每行一条，列之间用 **Tab（制表符）** 分隔。第一行以 `#` 开头，写列名，方便看。路径和参数里的 `{plugin_dir}` 会换成插件所在的文件夹，脚本可以和插件放在一起。

### actions.tsv（动作）

| 列 | 说明 |
|---|---|
| 内置 | 留空 |
| 标题 | 菜单里显示的名字 |
| 路径 | 要运行的程序 |
| 参数 | `{action_path}` 换成选中项的路径 |
| 热键 | 如 `Ctrl + Alt + N`，不要就留空 |
| 关键字 | “搜索词 关键字”回车直接执行 |
| 作用范围 | `app`（超级直达里）、`explorer`（资源管理器）、`any`（任意程序） |
| 适用于 | 空（全部）、`file`、`folder`、`app` |
| 扩展名 | 如 `txt;md` |
| 路径正则 | 路径匹配才出现 |

### commands.tsv（命令）

| 列 | 说明 |
|---|---|
| 内置 | 留空 |
| 关键字 | 在启动器里输入的简写 |
| 标题 | 结果里显示的名字 |
| 路径 | 要运行的程序 |
| 参数 | `{query}` 换成关键字后面的文字，`{current_folder}` 换成当前文件夹 |
| 工作目录 | 可以写 `{current_folder}` |
| 热键 | 不要就留空 |
| 静默 | `1` 不显示窗口 |
| 管理员 | `1` 以管理员身份运行 |
| 启用 | `1` 启用 |
| 作用范围 | 同上 |
| 显示在首页 | `1` 显示在首页“操作”和文件夹的动作菜单里 |

各列的含义和选项窗口里[动作](/guide/actions#自己加动作)、[命令](/guide/commands#自己加命令)的同名设置完全一样。最简单的写法：先用“新建示例插件”生成一份，照着改。

## 规则

- 插件的动作和命令排在你自己的后面，按同样的适用条件显示。
- 它们不会写进你自己的设置文件，选项的动作 / 命令页里也不显示，删掉插件就干净了。
- 插件只是文本文件，不加载别人的程序代码；写错了也不会让超级直达崩溃。

## 常见问题

**改了插件没生效？**
点 选项 → 插件 → 重新加载。再检查列之间是不是 Tab（有的编辑器会把 Tab 换成空格），文件是不是 UTF-8 编码。
