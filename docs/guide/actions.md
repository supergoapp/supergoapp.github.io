# 动作

动作是对选中结果做的“打开以外的事”：复制、剪切、复制路径、用某个程序打开、删除……启动器、首页、文件搜索窗口里都能用。

## 动作菜单

选中一个结果（文件、文件夹、应用都行），然后：

- 按 **Tab** 或 **Ctrl+O**；
- 或者光标在输入框末尾时按 **→**；
- 启动器里也可以在结果或首页的格子上点**右键**。

文件搜索窗口里用 Ctrl+O 打开动作菜单（那里的右键是系统右键菜单）。

菜单里有：

- **打开**；
- 选项里配置的动作：打开所在文件夹、复制、剪切、复制路径至剪贴板、使用 VS Code 编辑，以及你自己加的和插件提供的；
- **固定到启动器首页** / 从启动器首页取消固定；
- **删除**（放进回收站）、**复制文件名**；
- 勾了“显示在首页”的命令（在这个文件夹里打开命令行、PowerShell 等；对文件就在它所在的文件夹执行）；
- 应用还有**以管理员身份运行**；
- 最后是系统的右键菜单。

菜单里直接打字，按名称或关键字筛选，比如打“复制”只剩带“复制”的几项。光标在最前面时按 ← 或退格，或者按 Esc，回到结果列表，原来的输入还在。

## 动作热键

不进菜单，选中结果直接按热键：

| 动作 | 默认热键 |
|---|---|
| 打开所在文件夹 | Ctrl+Enter |
| 复制（文件本身，可以到资源管理器里粘贴） | Ctrl+C |
| 剪切 | — |
| 复制路径至剪贴板 | Ctrl+Shift+C |
| 使用 VS Code 编辑 | Alt+Shift+C |

输入框里选中了文字时，Ctrl+C 只复制文字。热键也能设成在资源管理器里、甚至任何程序里都有效，见[热键和作用范围](/guide/hotkeys)。

## 动作关键字

给动作填了关键字以后，在启动器里输入“**搜索词 关键字**”回车，直接对选中的结果执行。

例子：给“复制路径至剪贴板”填关键字 `cp`。输入 `报告 cp` → 结果只剩能复制路径的项，选中行右下角显示“Enter：复制路径至剪贴板”，回车 → 剪贴板里是报告的完整路径。

## 自己加动作

选项 → 动作：点 + 新建一条，填写：

| 项 | 说明 |
|---|---|
| 标题 | 菜单里显示的名字 |
| 路径 | 要运行的程序 |
| 参数 | `{action_path}` 换成选中项的完整路径，一般写成 `"{action_path}"`（带引号，路径里有空格也不怕） |
| 热键 | 见上 |
| 作用范围 | 热键在哪里有效，见[热键和作用范围](/guide/hotkeys) |
| 关键字 | 见上 |
| 适用于 | 全部 / 文件 / 文件夹 / 应用 |
| 扩展名 | 如 `md;txt`，只对这些文件出现；留空就是不限 |
| 路径正则 | 路径匹配这个正则才出现，比如 `\\src\\`（不区分大小写） |

“适用于”“扩展名”“路径正则”让动作只出现在合适的结果上，菜单不会越加越乱。自己加的动作默认不出现在应用上，要选“应用”才会出现。

### 例子：用记事本打开文本文件

- 标题：用记事本打开
- 路径：`notepad.exe`
- 参数：`"{action_path}"`
- 适用于：文件
- 扩展名：`md;txt;log`
- 关键字：`np`

确定后，搜一个 .md 文件按 Tab 就有“用记事本打开”，搜 .jpg 则没有；输入 `说明 np` 回车，直接用记事本打开。

### 例子：用 Photoshop 打开图片

- 路径：Photoshop.exe 的完整路径
- 参数：`"{action_path}"`
- 适用于：文件，扩展名 `jpg;png;psd`

插件也能加动作，适合一次分享一组，见[插件](/guide/plugins)。

## 常见问题

**自己加的动作在菜单里找不到？**
检查“适用于”和“扩展名”：比如适用于“文件”的动作不会出现在文件夹上；写了扩展名的动作只对这些文件出现。路径正则写错了会当作不匹配。

**Ctrl+Shift+C 不管用？**
有的输入法占用了 Ctrl+Shift+C，按键被输入法先拦掉了。在 选项 → 动作 里换一个热键。
