# 启动器首页

输入框为空时，启动器下面显示首页：不用打字就能打开常用的东西。每次打开启动器输入框都是空的，所以一打开就是首页；一打字就换成搜索结果，删空又回到首页。

## 四组内容

从上到下：

1. **最近使用**：在启动器里打开过的应用。
2. **固定**：自己固定的应用、文件夹、文件、命令。默认固定了“文件搜索”和“选项”。
3. **最近文件夹**：在启动器里打开过的文件夹，加上“打开 / 另存为”对话框里用过的文件夹。
4. **操作**：对一个文件夹执行的常用操作，默认有创建文件夹、打开命令行窗口、PowerShell、用 VS Code 打开、在此文件夹中搜索。

每个格子是图标加名字（名字最多两行）。

::: tip 只统计在启动器里打开的
“最近使用”只记在启动器里打开过的应用和文件夹（以及对话框里用过的文件夹），从开始菜单或资源管理器直接打开的不算。最近文件夹只列本地磁盘上的，网络路径不列。
:::

## 怎么用

| 按键 / 鼠标 | 作用 |
|---|---|
| ← → | 前后移动（Ctrl+N / Ctrl+P 也行） |
| ↑ ↓ | 跳到上一行 / 下一行里横向最近的格子 |
| Enter、鼠标单击 | 打开 |
| Ctrl+Enter | 打开所在文件夹 |
| Tab、Ctrl+O、鼠标右键 | 动作菜单：固定 / 取消固定、不再显示在最近使用、打开所在文件夹等 |

鼠标要在同一个格子上按下和松开才算点击，所以从别的窗口拖鼠标过来时不会误打开。

## “操作”对哪个文件夹执行

“操作”一行的标题会写明对象是哪个文件夹：

- **所选文件夹**：选中了一个文件夹格子（最近文件夹或固定的文件夹）时，操作对它执行。
- **当前文件夹**：从资源管理器、“打开 / 另存为”对话框或桌面呼出启动器时，是那里的当前文件夹。
- **资源管理器**：从别的程序呼出时，是最近用过的那个资源管理器窗口的文件夹（和对话框里按 Ctrl+G 跳去的是同一个）。
- **最近文件夹**：一个资源管理器窗口都没开时，是“最近文件夹”的第一个。

在“操作”一行里左右移动，对象不变。对当前文件夹执行“创建文件夹”时，资源管理器会直接跳进新文件夹。

例子：在资源管理器里打开 `D:\项目`，双击 Ctrl → 标题是“操作 · 当前文件夹 D:\项目”，选 PowerShell 回车 → 在 `D:\项目` 里打开 PowerShell。

### 加自己的操作

“操作”就是勾了“显示在首页”的命令，所以加一条命令就能加一个操作：

1. 选项 → 命令，新建一条命令（或选中已有的）。
2. 勾选“显示在启动器首页的‘操作’和文件夹的动作菜单里”。
3. 参数里写 `{current_folder}`，会换成那个文件夹。

例如给内置的 `hosts` 命令勾上，首页“操作”里就多一个“编辑 Hosts”。见[命令](/guide/commands#自己加命令)。

## 固定和取消固定

三个地方改的是同一份列表：

- 启动器的搜索结果上按 Tab 或右键 → “固定到启动器首页”。
- 首页的格子上按 Tab 或右键 → “固定到启动器首页” / “从启动器首页取消固定”。固定后启动器不关，这一项移到“固定”组。
- 选项 → 启动器首页 → 固定：添加文件夹、添加文件或程序、添加命令（包括“文件搜索窗口”），↑ ↓ 调顺序，删除。

## 不想看到某一项

在“最近使用”或“最近文件夹”里的格子上按 Tab 或右键 → **不再显示在最近使用**，它马上从首页消失。

想恢复：选项 → 启动器首页 → 最近记录列表里它标着“已隐藏”，选中点“取消隐藏”。

## 设置项

选项 → 启动器首页：

| 设置 | 说明 |
|---|---|
| 输入框为空时显示首页 | 默认勾选。取消后启动器打开时只有输入框，也不再清空上次的输入 |
| 固定 | 添加、排序、删除固定的项 |
| 排序 | **综合**（默认）：次数越多越靠前，但每过两周分量减半，很久不用的会慢慢掉下去；**最近时间**；**使用次数** |
| 应用最多 / 文件夹最多 | 每组显示几个，0～8；填 0 就不显示这一组 |
| 最近记录列表 | 每一项的使用次数和时间，可以隐藏、取消隐藏 |
| 清除全部使用记录 | 立即清空。也会影响搜索结果里按使用习惯的排序 |

## 常见问题

**“操作”一行没有出现？**
没开资源管理器、也没有任何最近文件夹时，没有可以执行的对象，这一行就不显示。在启动器里打开过一次文件夹以后就有了。

**刚打开的应用没出现在“最近使用”里？**
只统计在启动器里打开的。另外检查 选项 → 启动器首页 → 应用最多 是不是 0，或者它被隐藏了。
