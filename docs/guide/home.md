# 启动器首页

输入框为空时，启动器下面显示首页，不用打字就能打开常用的东西。一打字就换成搜索结果，删空又回到首页。

## 四组内容

1. **最近使用**：启动器里打开过的应用。
2. **固定**：自己固定的应用、文件夹、文件、命令。默认固定了“文件搜索”和“选项”。
3. **最近文件夹**：启动器里打开过的文件夹，加上“打开 / 保存”对话框里用过的文件夹。
4. **操作**：对一个文件夹执行的常用操作，默认有创建文件夹、打开命令行窗口、PowerShell、用 VS Code 打开、在此文件夹中搜索。

## 操作对哪个文件夹

- 选中一个文件夹格子时，“操作”作用于它（标题写着“所选文件夹”）。
- 没选文件夹时，作用于默认文件夹：从资源管理器、对话框或桌面呼出时是它的当前文件夹；从别的程序呼出时是最近用过的资源管理器窗口的文件夹；都没有时是最近文件夹的第一个。

想加别的操作：选项 → 命令，新建或选中一条命令，勾选“显示在启动器首页的操作和文件夹的动作菜单里”。参数里的 `{current_folder}` 会换成那个文件夹。

## 操作方式

- ← → 前后移动，↑ ↓ 跳到上一行 / 下一行；Enter 打开，Ctrl+Enter 打开所在文件夹。
- Tab 或右键：动作菜单，可以固定 / 取消固定、不再显示在最近使用、打开所在文件夹等。

## 设置

选项 → 启动器首页：

- 固定的项：添加文件夹、文件或程序、命令，调整顺序，删除。
- 最近使用的排序：**综合**（默认，次数多的靠前，很久没用的慢慢往后）、最近时间、使用次数；应用和文件夹各显示几个（0～8）。
- 最近记录列表：看每一项的使用次数和时间，隐藏不想看到的，取消隐藏，或清除全部记录。
- 不想要首页：取消勾选“输入框为空时显示首页”。
