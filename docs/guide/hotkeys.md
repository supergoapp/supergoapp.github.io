# 热键和作用范围

超级直达的热键分两类：程序本身的热键（呼出启动器、文件搜索窗口、快速切换等），和每个动作、命令自己的热键。动作和命令的热键可以选“作用范围”：只在超级直达里有效，还是在资源管理器、甚至任何程序里都有效。

## 程序的热键

选项 → 热键：

| 热键 | 默认 | 作用 |
|---|---|---|
| 显示超级直达 | 双击 Ctrl | 呼出启动器。可以录成普通组合键，或点“重置为‘双击 Ctrl’” |
| 再次按下时 | 切换到文件搜索窗口 | 启动器开着时再按一次：带着输入切到文件搜索窗口，或者隐藏启动器 |
| 在全屏游戏和应用中禁用 | 勾选 | 全屏时不响应上面的热键 |
| 文件搜索窗口 | 无 | 直接打开文件搜索窗口 |
| 快速切换 | Ctrl+G | 在“打开 / 另存为”对话框里跳到最近用过的资源管理器文件夹，见[对话框快速切换](/guide/dialog) |
| 显示弹出菜单 | 无 | 见[弹出菜单](/guide/popup-menu) |
| 下一项 / 上一项 | Ctrl+N / Ctrl+P | 在启动器和文件搜索窗口里选择（↑ ↓ 也行） |
| 预览 | Alt+P | 显示 / 隐藏预览 |
| 动作 | Ctrl+O | 打开动作菜单 |

**怎么改**：点一下热键框，直接按下新的组合键，框里就显示出来；按 Backspace 清空。点“应用”或“确定”后生效。

## 作用范围

在 选项 → 动作 或 选项 → 命令 里选中一条，给它设热键，再选“作用范围”：

| 作用范围 | 热键在哪里有效 | 对什么执行 |
|---|---|---|
| **超级直达**（默认） | 只在启动器和文件搜索窗口里 | 选中的结果 |
| **资源管理器** | 资源管理器或桌面在前台时 | 动作：资源管理器里选中的文件；命令：当前文件夹 |
| **任意程序** | 任何时候 | 动作：只在资源管理器 / 桌面里有选中文件时才有对象；命令：在当前文件夹执行（不在资源管理器里时是用户文件夹） |

“资源管理器”范围的热键只在资源管理器或桌面在前台时才生效，在别的程序里按，那个程序照常收到这个组合键，不会被抢走。

### 例子

- 把 `psh` 的作用范围改成“资源管理器”：在资源管理器里按 **Ctrl+Shift+R**，就在当前文件夹打开 PowerShell；在记事本里按则没反应。
- 给“复制路径至剪贴板”设热键 **Ctrl+Alt+Y**、作用范围“资源管理器”：在资源管理器里选中文件按 Ctrl+Alt+Y，剪贴板里就是它的路径。
- 改成“任意程序”后，在哪都能按。

## 常见问题

**设了热键但不管用？**
- 被别的程序占用了：“资源管理器”“任意程序”范围的热键要向系统注册，别的程序先占了就注册不上。换一个组合键试试。
- 被输入法拦掉了：有的输入法自己用了 Ctrl+Shift+C 之类的组合键，按键到不了超级直达。
- 忘了点“应用”或“确定”。

**能不能不用双击 Ctrl？**
可以。选项 → 热键 → 显示超级直达，点热键框按下想要的组合键（比如 Alt+Space）。想换回来点“重置为‘双击 Ctrl’”。
