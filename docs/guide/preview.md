# 文件预览

不用打开程序，直接看文件内容：在启动器和文件搜索窗口里都能用。

## 怎么用

- **启动器**：选中一个文件按 **Alt+P**，启动器变宽，右边显示内容，下面是文件名和路径。再按一次关闭。开关状态会记住。
- **文件搜索窗口**：右边就是预览区，Alt+P 或底部的开关显示 / 隐藏。

按 ↑ ↓ 换结果，预览跟着换；按住方向键快速移动也不卡。预览时输入框照样能打字。

## 能看哪些文件

超级直达用的是 Windows 自带的预览程序，和资源管理器的“预览窗格”是同一套：

| 类型 | 显示 |
|---|---|
| 图片 | 图片本身 |
| 文本、代码、Markdown | 内容。装了对应的预览程序时，Markdown 显示渲染后的效果、代码带语法高亮；没装时用只读文本框显示原文 |
| PDF | 页面（需要装了 PDF 预览程序，比如 Adobe Reader 等） |
| Word、Excel、PPT | 内容（需要装了 Office 或带预览程序的办公软件） |
| 其他 | 缩略图或大图标 |

资源管理器的预览窗格能看的，这里一般也能看。装了额外的预览插件（给 Markdown、代码、压缩包等加预览的工具），这里也会跟着能看。

## 设置项

| 位置 | 设置 |
|---|---|
| 选项 → 热键 → 预览 | 预览的热键，默认 Alt+P |

## 常见问题

**PDF 或 Office 文件只显示图标？**
本机没有对应的预览程序。在资源管理器里打开预览窗格（Alt+P）看看同一个文件，如果那里也不行，装上对应的软件即可。
