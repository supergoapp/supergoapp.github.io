# 启动器

在任何窗口里连按两下 Ctrl（每次按住不超过 0.4 秒，中间不按别的键），屏幕上部弹出启动器。全屏玩游戏、看视频时默认不响应。热键可以在 选项 → 热键 里改成普通组合键。

## 能搜什么

| 输入 | 结果 |
|---|---|
| 应用名、拼音全拼、首字母 | 开始菜单里的应用，包括商店应用：`jsb` → 记事本，`vsc` → Visual Studio Code |
| 文件名、文件夹名 | 用 Everything 搜，名字以输入开头的、路径浅的、常用的排前面 |
| 网页搜索关键字 + 词 | `b 天气`（百度）、`g`（Google）、`bing`、`wiki` 等，可在 选项 → 网络搜索 里增删 |
| 网址、路径 | `github.com` 打开网页，`%APPDATA%`、`C:\Windows` 打开文件夹 |
| 命令 | `cmd`、`psh`、`mkdir 名字`、`..` 等，见[命令和动作](/guide/commands) |
| 过滤器 | 在任意位置写 `folder:` `file:` `doc:` `pic:` `video:` `audio:`，只搜这一类 |
| `?` | 列出搜索语法速查，见[搜索语法](/guide/syntax) |

## 按键

| 按键 | 作用 |
|---|---|
| ↑ ↓、Ctrl+N / Ctrl+P | 选择 |
| Enter | 打开（命令则执行） |
| Ctrl+Enter | 打开所在文件夹并选中 |
| Tab、Ctrl+O，或光标在末尾时按 → | 动作菜单（复制、剪切、复制路径、用 VS Code 编辑、删除、固定到首页等） |
| Alt+P | 在右边预览选中的文件 |
| 再连按两下 Ctrl | 带着输入切到文件搜索窗口，看更多文件结果 |
| Esc | 关闭 |

输入框右边两个按钮：打开文件搜索窗口、打开选项。按住输入框那一行空白处可以拖动启动器，位置会记住。

## 动作关键字

给动作设了关键字（选项 → 动作）以后，输入“搜索词 关键字”回车，就直接对选中的结果执行这个动作。比如给“复制路径至剪贴板”设关键字 `cp`，输入 `报告 cp` 回车，剪贴板里就是报告文件的路径。
