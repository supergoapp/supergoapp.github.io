# 启动器

启动器是超级直达的主界面：一个随叫随到的搜索框，输入几个字就能打开应用、文件、文件夹、网页，或者执行命令。

## 呼出和关闭

- **呼出**：在任何窗口里**连按两下 Ctrl**。屏幕上部弹出启动器，输入框里已经有光标，直接打字就行。
- **关闭**：按 Esc，或者点到启动器外面的地方。打开了某一项之后，启动器也会自动关闭。
- 托盘图标左键单击也能打开启动器。

“连按两下”的要求：每次按住 Ctrl 不超过 0.4 秒，两次之间不超过 0.4 秒，中间不按别的键。所以平时按 Ctrl+C、Ctrl+V 不会误弹出来。

全屏玩游戏、看视频时，默认不响应双击 Ctrl，免得打断你。

## 能搜什么

| 输入 | 结果 |
|---|---|
| 应用名、拼音全拼、拼音首字母 | 开始菜单里的应用，包括商店应用。`jsb`、`jishiben` → 记事本，`vsc` → Visual Studio Code |
| 文件名、文件夹名 | 用 Everything 搜整台电脑。名字以输入开头的、路径浅的、你常打开的排前面 |
| 网页搜索关键字 + 词 | `b 天气` 用百度搜，`g`、`bing`、`wiki` 等，见[网页搜索、网址和路径](/guide/web) |
| 网址、路径 | `github.com` 打开网页，`C:\Windows`、`%APPDATA%` 打开文件夹 |
| 命令 | `cmd`、`psh`、`mkdir 名字`、`..` 等，见[命令](/guide/commands) |
| 过滤器 | 在任意位置写 `folder:` `file:` `doc:` `pic:` `video:` `audio:`，只搜这一类 |
| 搜索语法 | `ext:jpg;png`、`size:>100mb`、`报告 !草稿` 等，见[搜索语法](/guide/syntax) |
| `?` | 列出搜索语法速查（全角的“？”也行） |

结果的排序会参考你的习惯：在启动器里打开得越多、越近的项，排得越靠前。

不打字的时候，启动器下面显示[首页](/guide/home)：最近用过的应用、固定的项、最近的文件夹和常用操作。

### 拼音

应用名支持拼音：全拼（`jishiben`）、首字母（`jsb`），多音字按词组读（比如“重庆”读 chongqing）。拼音靠 Windows 自带的中文输入法组件来读，系统里没有中文输入法时只能按字面搜。

文件和文件夹的名字暂时不支持拼音（`sucai` 搜不到“素材”），在计划中。

### 过滤器

过滤器是一类文件的简写，写在输入的任意位置都行：

| 过滤器 | 只搜 |
|---|---|
| `folder:` | 文件夹 |
| `file:` | 文件 |
| `doc:` | 文档（Word、Excel、PPT、WPS、PDF、txt、md、epub 等） |
| `pic:` | 图片（jpg、png、gif、webp、heic、psd 等） |
| `video:` | 视频（mp4、mkv、avi、mov 等） |
| `audio:` | 音频（mp3、flac、wav、m4a 等） |

例子：`src folder:` 只要叫 src 的文件夹；`pic: 截图` 只要名字里有“截图”的图片。过滤器可以在 选项 → 文件搜索 → 过滤器 里改，也能加自己的。

## 按键

| 按键 | 作用 |
|---|---|
| ↑ ↓、Ctrl+N / Ctrl+P | 上一项 / 下一项 |
| Enter | 打开（命令则执行） |
| Ctrl+Enter | 打开所在文件夹，并选中这个文件 |
| Tab、Ctrl+O，或光标在输入框末尾时按 → | 打开[动作菜单](/guide/actions)：复制、剪切、复制路径、用 VS Code 编辑、删除、固定到首页等 |
| Ctrl+C | 复制选中的文件（输入框里选中了文字时，只复制文字） |
| Alt+P | 在右边预览选中的文件，再按一次关闭 |
| 再连按两下 Ctrl | 带着输入切到[文件搜索窗口](/guide/file-search)，看更多文件结果 |
| Esc | 关闭 |

这些按键都能在 选项 → 热键 里改，见[热键和作用范围](/guide/hotkeys)。

## 预览

按 **Alt+P**，启动器变宽，右边显示选中文件的内容：文本、代码、Markdown、图片、PDF、Office 文档等。上下换结果，预览跟着换，输入框照样能打字。开关状态会记住，下次打开还是一样。详见[文件预览](/guide/preview)。

## 动作关键字

给动作设了关键字以后（选项 → 动作 → 关键字），输入“**搜索词 关键字**”回车，就直接对选中的结果执行这个动作，不用进菜单。

例子：给“复制路径至剪贴板”设关键字 `cp`，输入 `报告 cp`，结果里只剩能复制路径的项，选中行右下角写着“Enter：复制路径至剪贴板”，回车后剪贴板里就是报告的路径。

## 输入框右边的两个按钮

- **方框加箭头**：打开文件搜索窗口，带着输入框里的文字。
- **齿轮**：打开选项。

## 拖动位置

按住输入框那一行的空白处（放大镜附近）可以拖动启动器，位置会记住。想回到默认位置（屏幕上部居中）：选项 → 常规设置 → 启动器位置 → 重置。

## 没装或没运行 Everything 时

搜文件要靠 [Everything](https://www.voidtools.com/downloads/)（免费）。超级直达会自己处理大部分情况，结果列表第一项会给出提示：

| 情况 | 提示 | 点一下 |
|---|---|---|
| 装了但没运行 | 正在启动 Everything…（启动后会自动显示文件结果） | 超级直达自动在后台启动它，一般不到 1 秒就出结果 |
| 自动启动没成功 | Everything 没有运行 / Everything 启动失败 | 启动或重试 |
| 没装 | 没有安装 Everything | 打开 Everything 官网的下载页 |
| 缺少 Everything64.dll | 请重新安装超级直达 | — |

没有 Everything 时，应用搜索、命令、网页搜索、对话框快速切换照常能用。

## 设置项

| 位置 | 设置 |
|---|---|
| 选项 → 热键 → 显示超级直达 | 呼出启动器的热键：默认双击 Ctrl，可以录成普通组合键，或点“重置为‘双击 Ctrl’” |
| 选项 → 热键 → 再次按下时 | 启动器已经打开时再按一次热键：切换到文件搜索窗口（默认），或隐藏启动器 |
| 选项 → 热键 → 在全屏游戏和应用中禁用 | 默认勾选 |
| 选项 → 常规设置 → 启动器位置 | 重置到屏幕上部居中 |
| 选项 → 文件搜索 → 过滤器 | 增删改过滤器 |
| 选项 → 网络搜索 | 网页搜索的关键字和网址 |
| 选项 → 启动器首页 | 首页的内容和排序，见[启动器首页](/guide/home) |

## 常见问题

**双击 Ctrl 没反应？**
两次要按得快，中间不能按别的键；全屏程序里默认不响应。也可以把热键换成普通组合键，见[常见问题](/guide/faq#双击-ctrl-没反应)。

**搜不到文件，只有应用？**
看结果第一项有没有 Everything 的提示，按提示点一下。目前支持 Everything 1.4，1.5 测试版暂不支持。

**想看更多文件结果？**
在启动器里再连按两下 Ctrl，或点输入框右边第一个按钮，打开文件搜索窗口。
