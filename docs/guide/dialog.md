# 对话框快速切换

保存文件时，对话框默认停在“文档”里，想存到刚才资源管理器里开着的文件夹，得一层层点过去。超级直达在“打开 / 另存为”对话框下方加一条工具栏，一下就跳过去。

## 工具栏上有什么

在任何程序里打开“打开 / 另存为”对话框，下方都会出现这条工具栏：

- **资源管理器里打开的文件夹**：一个个列出来，点一下对话框就跳过去。
- **搜索框**：搜文件夹和文件。选中文件夹就跳过去；选中文件就跳到它所在的文件夹，并填好文件名。↑ ↓ 选择，Enter 跳转，Esc 清空。
- **☆ 收藏**：收藏的文件夹，点一个就跳；菜单里还能“收藏当前文件夹”和移除收藏（也可以在 选项 → 菜单 里改）。
- **🕒 历史**：在对话框里用过的文件夹。
- **🔧 工具**：复制当前文件夹路径、在资源管理器中打开当前文件夹、切到资源管理器正在看的文件夹。

## Ctrl+G：直接跳

对话框开着时按 **Ctrl+G**，直接跳到最近用过的那个资源管理器窗口的文件夹，连工具栏都不用点。

## 例子

在资源管理器里打开了 `D:\项目\设计稿`，然后在别的程序里点“另存为” → 工具栏里就有“设计稿”，点它，或按 Ctrl+G，对话框直接到了这个文件夹，文件名照常输入保存。

在工具栏搜索框里输入 `notepad.exe`，选中回车 → 对话框跳到 `C:\Windows\System32`（它所在的文件夹），文件名也填好了。

## 哪些程序能用

用 Windows 标准“打开 / 另存为”对话框的程序都能用，比如记事本、画图、浏览器上传文件、新版 QQ 发送文件。对话框里有地址栏的，跳转都走地址栏，所以像新版 QQ 这种接管了“打开”按钮的程序，点文件夹也只是跳过去，不会把文件夹直接发出去。

用自己做的对话框的程序（比如 WPS 的内置对话框）暂时不支持。

## 设置项

| 位置 | 设置 |
|---|---|
| 选项 → 热键 → 快速切换 | 跳转的热键，默认 Ctrl+G |
| 选项 → 菜单 | 收藏的文件夹（工具栏的 ☆ 和[弹出菜单](/guide/popup-menu)共用） |
| 选项 → 第三方集成 | 分别开关“文件对话框”“文件夹对话框”上的工具栏 |

## 常见问题

**对话框下面没有工具栏？**
- 检查 选项 → 第三方集成 里是否关掉了“文件对话框”。
- 那个程序是以管理员身份运行的：超级直达也要以管理员身份运行，否则没法控制它的对话框。
- 程序用的是自己画的对话框，暂不支持。

**Ctrl+G 跳的不是我想要的文件夹？**
跳的是**最近激活**的那个资源管理器窗口。先点一下想要的资源管理器窗口，再回到对话框按 Ctrl+G；或者直接点工具栏上列出的文件夹。

**Ctrl+G 和程序自己的快捷键冲突？**
在 选项 → 热键 → 快速切换 里换一个。
