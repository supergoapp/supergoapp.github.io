# 对话框快速切换

在任何程序里打开“打开 / 另存为”对话框时，对话框下方会多出一条工具栏，帮你快速跳到想要的文件夹。

## 工具栏上有什么

- **资源管理器里打开的文件夹**：一个个列出来，点一下对话框就跳过去。
- **Ctrl+G**：直接跳到最近用过的那个资源管理器窗口的文件夹（快捷键可在 选项 → 热键 → 快速切换 里改）。
- **搜索框**：搜文件夹和文件；选中文件时，对话框跳到它所在的文件夹并填好文件名。↑ ↓ 选择，Enter 跳转，Esc 清空。
- **☆ 收藏**：选项 → 菜单 里的收藏夹。
- **🕒 历史**：对话框里用过的文件夹。
- **🔧 工具**：复制当前文件夹路径、在资源管理器中打开当前文件夹、切到资源管理器正在看的文件夹。

## 例子

在资源管理器里打开了 `D:\项目\设计稿`，然后在别的程序里点“另存为” → 对话框下方工具栏里就有“设计稿”，点它，或按 Ctrl+G，对话框直接到了这个文件夹。

## 停用

选项 → 第三方集成：可以分别关掉文件对话框、文件夹对话框上的工具栏。

如果对话框所属的程序是以管理员身份运行的，超级直达也要以管理员身份运行，否则没法控制那个对话框。
