# 搜索语法

启动器、文件搜索窗口、对话框工具栏的搜索框、资源管理器里打字即搜，查文件都交给 Everything，输入原样传过去，所以 Everything 的写法都能用。

## 忘了怎么写时

- **启动器**：只输入 `?`（全角的“？”也行），列出常用写法，每项带例子。选中一项回车，例子就填进输入框，接着改就行。
- **文件搜索窗口**：点搜索框右端的“?”，弹出速查，点一行把例子填进搜索框；还没输入时，列表中间也有几个可以点的例子。
- 输入框的灰色提示里也写着“输入 ? 查看搜索语法”。

## 平时怎么搜

直接输入名字的一部分就行，不分大小写：`周报` 能找到“第43周周报.docx”。超级直达会把**名字以输入开头的**、路径浅的、常打开的排在前面。

输入里带了 `\ : * ? " | < > !` 这些符号时，就完全按你写的语法搜。

## 组合

| 写法 | 作用 | 例子 |
|---|---|---|
| 空格 | 同时包含（且） | `报告 2026` |
| `\|` | 或 | `*.mp4\|*.mkv` |
| `!` | 排除 | `报告 !草稿` |
| `< >` | 分组 | `<报告\|总结> 2026` |
| `" "` | 带空格的词或路径 | `"c:\program files\" *.exe` |

## 名字

| 写法 | 作用 | 例子 |
|---|---|---|
| `*` `?` | 通配符：任意多个 / 一个字符。写了通配符就要整个名字匹配 | `*.mp4`、`报告??.docx` |
| `startwith:` | 名字以…开头 | `startwith:IMG_` |
| `endwith:` | 名字以…结尾 | `endwith:_final` |
| `case:` | 区分大小写 | `case:README` |
| `regex:` | 正则表达式 | `regex:^IMG_\d+\.jpg$` |

## 类型和位置

| 写法 | 作用 | 例子 |
|---|---|---|
| `ext:` | 扩展名，分号分隔 | `ext:jpg;png` |
| `file:` / `folder:` | 只要文件 / 只要文件夹 | `folder:下载` |
| `doc:` `pic:` `video:` `audio:` | 按类型（超级直达的过滤器，可在 选项 → 文件搜索 → 过滤器 里改、加） | `pic: 截图` |
| 带 `\` | 连路径一起匹配 | `\downloads *.pdf` |
| `parent:` | 只看某个文件夹里直接的内容（不含子文件夹） | `parent:c:\windows` |
| `empty:` | 空文件夹 | `empty:` |

## 大小和时间

| 写法 | 作用 | 例子 |
|---|---|---|
| `size:` | 大小，单位 kb、mb、gb | `size:>100mb`、`size:1mb..10mb` |
| `dm:` | 修改日期 | `dm:today`、`dm:thisweek`、`dm:>=2026-10-01` |
| `dc:` | 创建日期 | `dc:lastmonth` |

日期的常用写法：`today`、`yesterday`、`thisweek`、`lastweek`、`thismonth`、`lastmonth`、`thisyear`，或具体日期 `2026-10-01`，范围用 `..`：`dm:2026-10-01..2026-10-31`。

## 内容

| 写法 | 作用 | 例子 |
|---|---|---|
| `content:` | 按文件内容搜 | `ext:txt content:密码` |

按内容搜要逐个读文件，很慢，最好和位置或类型一起用，先把范围缩小。

## 组合起来

| 想找 | 写法 |
|---|---|
| 下载文件夹里的 PDF | `\downloads\ *.pdf` |
| 今天改过的 Word 文档 | `ext:doc;docx dm:today` |
| 大于 1 GB 的视频 | `video: size:>1gb` |
| 名字有“合同”但不是扫描件的 | `合同 !扫描` |
| D 盘里的空文件夹 | `d:\ empty:` |
| 本月拍的照片 | `pic: dc:thismonth` |

## 拼音

应用名支持拼音（`jsb` → 记事本）；文件和文件夹名暂不支持拼音，`sucai` 搜不到“素材”（在计划中）。

完整的写法以 [Everything 官方说明](https://www.voidtools.com/support/everything/searching/) 为准。
