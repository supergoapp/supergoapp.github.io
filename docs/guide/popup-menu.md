# 弹出菜单

按一个热键，在鼠标旁边弹出一个菜单：收藏的文件夹和最近的文件夹。在资源管理器或“打开 / 另存为”对话框里选一项，它就直接跳过去。

## 先设热键

弹出菜单默认没有热键：

1. 选项 → 热键 → 显示弹出菜单，点热键框，按下想用的组合键（比如 Ctrl+Alt+M）。
2. 点“确定”。

## 怎么用

在资源管理器或对话框里按这个热键，鼠标所在的位置弹出菜单：

- **收藏**：默认有快速访问、此电脑、文档，可以自己加；
- **最近**：子菜单里是最近用过的 10 个文件夹；
- **选项**：打开选项窗口。

选一项，资源管理器或对话框就跳到那个文件夹。“此电脑”“快速访问”这类系统位置也能跳。在别的程序里按热键也能弹出，选中的文件夹会在新的资源管理器窗口里打开。

## 改收藏

选项 → 菜单：添加、删除收藏的文件夹，改名称和路径。在[对话框工具栏](/guide/dialog)的 ☆ 里也能“收藏当前文件夹”。两处用的是同一份收藏。

## 设置项

| 位置 | 设置 |
|---|---|
| 选项 → 热键 → 显示弹出菜单 | 热键，默认没有 |
| 选项 → 菜单 | 收藏的文件夹 |

## 常见问题

**按了热键没反应？**
热键可能被别的程序占用了，换一个组合键试试；也可能是没点“确定”或“应用”。
