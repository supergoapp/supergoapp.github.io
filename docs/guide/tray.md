# 托盘和命令行

## 托盘图标

超级直达运行时，屏幕右下角的托盘里有它的图标（如果没看到，点托盘的 ^ 展开）。

- **左键单击**：打开启动器。
- **右键**：菜单。

| 菜单项 | 作用 |
|---|---|
| 打开启动器 | 同双击 Ctrl |
| 打开新的文件搜索窗口 | 见[文件搜索窗口](/guide/file-search) |
| 选项 | 见[选项一览](/guide/options) |
| 帮助文档 | 打开使用说明 |
| 关于 | 版本号 |
| 退出 | 退出超级直达，热键、对话框工具栏等都会停止 |

## 命令行

超级直达同时只运行一个。已经在运行时，再用下面的参数启动 `SuperGo.exe`，会让正在运行的那个去做对应的事：

| 命令 | 作用 |
|---|---|
| `SuperGo.exe` | 启动，常驻托盘 |
| `SuperGo.exe --show` | 打开启动器 |
| `SuperGo.exe --filesearch` | 打开文件搜索窗口 |
| `SuperGo.exe --filesearch 词` | 打开文件搜索窗口并搜这个词 |
| `SuperGo.exe --options` | 打开选项 |
| `SuperGo.exe --quit` | 退出正在运行的超级直达 |

用处：给其他软件（比如鼠标手势、快捷键工具、Stream Deck）绑一个动作，运行 `SuperGo.exe --filesearch` 就能打开文件搜索窗口。
