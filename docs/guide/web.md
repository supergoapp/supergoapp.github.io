# 网页搜索、网址和路径

在启动器里不光能搜本机，还能直接搜网站、打开网址和文件夹。

## 网页搜索

输入“**关键字 搜索词**”，第一项就是“在 某网站 中搜索 搜索词”，回车用默认浏览器打开。

例子：`b 天气` → 用百度搜“天气”；`wiki Windows` → 在维基百科里搜 Windows。

默认的关键字：

| 关键字 | 网站 |
|---|---|
| `b` | 百度 |
| `g` | Google |
| `bing` | Bing |
| `wiki` | Wikipedia |
| `so` | Stack Overflow（通过 Google 搜） |
| `youtube` | YouTube |
| `maps` | Google 地图 |
| `amazon` | Amazon |
| `ebay` | eBay |
| `imdb` | IMDb |
| `gmail` | Gmail（不用搜索词，直接打开） |
| `twitter` | Twitter（直接打开） |
| `facebook` | Facebook（直接打开） |

另外，不管输入什么，结果的最后一项总是“在百度中搜索”，本机搜不到时回车就能上网搜。

### 加自己的网站

选项 → 网络搜索：点 + 新建，填三项：

- **关键字**：在启动器里输入的简写，比如 `zh`。
- **标题**：结果里显示的名字，比如“知乎”。
- **网址**：搜索词的位置写 `{query}`，比如 `https://www.zhihu.com/search?q={query}`。网址里没有 `{query}` 时就是直接打开这个网站。

不想要的网站取消勾选即可。

## 网址

输入网址直接打开：`github.com`、`https://supergoapp.github.io`。像 `readme.txt` 这样的文件名不会被当成网址。

## 路径

输入完整的文件夹或文件路径，回车直接打开：

- `C:\Windows` → 打开这个文件夹
- `%APPDATA%`、`%TEMP%` 这类环境变量也认

打开文件夹默认用资源管理器，也可以换成别的文件管理器：选项 → 常规设置 → 打开文件夹用，填它的路径和参数。

## 常见问题

**输入 `b 天气` 第一项不是网页搜索？**
检查 选项 → 网络搜索 里百度那一行是否勾选、关键字是不是 `b`。关键字和搜索词之间要有空格。
