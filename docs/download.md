# 下载

**即将提供。** 第一个测试版（0.9）正在准备，发布后会放在 GitHub 的 [Releases](https://github.com/supergoapp/supergo-release/releases) 页面：

| 文件 | 说明 |
|---|---|
| `SuperGo-<版本>-x64-Setup.exe` | 安装包（推荐），双击安装 |
| `SuperGo-<版本>-x64-Portable.zip` | 便携版，解压即用 |

## 系统要求

- Windows 10、11（64 位）
- 搜索文件需要 [Everything](https://www.voidtools.com/downloads/)（免费）。装了没运行时，超级直达会自动在后台启动它；没装时，软件里有提示和下载入口。不装 Everything 也能用应用搜索、命令、网页搜索和对话框快速切换。

## 问题反馈

在 [supergo-release 的 Issues](https://github.com/supergoapp/supergo-release/issues) 里提。
