# 安装与开始使用

## 安装

1. 从[下载页](/download)下载安装包，双击安装；或者下载便携版，解压到任意文件夹，运行 `SuperGo.exe`。
2. 装好 [Everything](https://www.voidtools.com/downloads/)（用来搜文件，免费）。不想装也行，只是搜不了文件。装了没运行时，超级直达会自动在后台启动它。
3. 运行后，屏幕右下角的托盘里出现超级直达的图标。

想开机自动启动：右键托盘图标 → 选项 → 常规设置 → 勾选“在 Windows 启动时启动超级直达”。

## 五分钟上手

### 1. 呼出启动器

在任意窗口里**连按两下 Ctrl**，屏幕上部弹出搜索框。按 Esc 或点别处关闭。

### 2. 看看首页

不打字时，下面是[首页](/guide/home)：最近用过的应用、固定的项、最近的文件夹，以及对文件夹的常用操作。方向键选，回车打开。

### 3. 打几个字搜一搜

| 输入 | 结果 |
|---|---|
| `jsb` 或 `jishiben` | 记事本（应用支持拼音） |
| `readme` | 名字里有 readme 的文件和文件夹 |
| `pic: 截图` | 只搜图片 |
| `b 天气` | 用百度搜“天气” |
| `cmd` | 在当前文件夹打开命令提示符 |
| `?` | 搜索语法速查 |

选中结果后：Enter 打开，Ctrl+Enter 打开所在文件夹，**Tab** 打开动作菜单（复制、复制路径、删除、固定到首页……），Alt+P 预览。

### 4. 在“另存为”里试试

先在资源管理器里打开一个文件夹，再到记事本里按 Ctrl+S。对话框下方多了一条工具栏，点上面的文件夹，或者直接按 **Ctrl+G**，对话框就跳过去了。见[对话框快速切换](/guide/dialog)。

### 5. 在资源管理器里直接打字

点一下资源管理器文件列表的空白处，直接输入几个字，就在当前文件夹里搜。见[资源管理器里打字即搜](/guide/explorer)。

## 设置存在哪里

`%APPDATA%\SuperGo`：设置、固定的项、使用记录、插件都在这里。换电脑时把这个文件夹复制过去即可。
