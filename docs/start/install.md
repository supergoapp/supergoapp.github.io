# 安装与开始使用

## 安装

1. 从[下载页](/download)下载安装包，双击安装；或者下载便携版，解压到任意文件夹，运行 `SuperGo.exe`。
2. 装好 [Everything](https://www.voidtools.com/downloads/)（用来搜文件，免费）。不想装也行，只是搜不了文件。
3. 运行后，屏幕右下角的托盘里出现超级直达的图标。

想开机自动启动：右键托盘图标 → 选项 → 常规设置 → 勾选“在 Windows 启动时启动超级直达”。

## 第一次使用

1. 在任意窗口里**连按两下 Ctrl**，屏幕上部弹出搜索框。
2. 不打字时，下面是首页：最近用过的应用、固定的项、最近的文件夹，以及对文件夹的常用操作。方向键选，回车打开。
3. 打几个字就开始搜：
   - `jsb` 或 `jishiben` → 记事本（应用支持拼音）
   - `readme` → 名字里有 readme 的文件和文件夹
   - `b 天气` → 用百度搜“天气”
   - `cmd` → 在当前文件夹打开命令提示符
4. 按 Esc 或点别处关闭。

## 托盘菜单

右键托盘图标：打开启动器、打开新的文件搜索窗口、选项、帮助文档、关于、退出。左键单击直接打开启动器。

## 设置存在哪里

`%APPDATA%\SuperGo`：设置、固定的项、使用记录、插件都在这里。换电脑时把这个文件夹复制过去即可。
